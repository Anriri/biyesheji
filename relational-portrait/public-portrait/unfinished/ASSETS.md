# Original preset portraits

v1.png and v2.png are original AI-generated illustrations created for this prototype. The depicted adult participant is fictional. V2 was generated by editing V1 with the same person, framing, garment and paper-room metaphor, opening the right arc toward the distant terrain. Both are normalized to 1024 × 1280 (4:5).

These are fixed demonstration assets, not runtime OpenAI API results. The sample indicates career 6 → 4 and exploration 1 → 3; arbitrary form edits do not regenerate them. The interface labels demo mode continuously. No uploaded participant photograph was used to make these assets.
