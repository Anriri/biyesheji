# 未名生物收容所 · 隔空捏塑实验室

一个可在浏览器中运行的毕业设计交互原型。原创小生物「弥弥」由连续 SVG 曲线绘制；摄像头画面通过 **MediaPipe Hands 的真实手部识别**生成 21 个手部关键点，驱动耳朵和身体的软形变。

## v3 · 有边界的自由塑形

保留现有页面、珠光弥弥和真实摄像头识别，优化实际几何变形，使角色适合向可爱 IP 挂件造型方向探索。

- 主体、五官、两只耳朵及四肢保持完整；可独立调整耳长、耳宽、主体胖瘦与高扁、肢体比例。
- 每个部位有连续的柔软变形范围；达到边界会停止继续拉长，不会产生新尖刺或分叉。
- 鼠标塑形与隔空手势共用同一套受限几何，支持涂色、自选颜色、表情、弹性与撤销。
- 松手后保留用户选择的比例，不自动恢复初始形态；只有手动重置才复原。
- 目前提供 2D 视觉原型，不代表已通过实体挂件的结构强度或生产工艺验证。

### 尖刺原因与算法修改

旧算法用狭窄的高斯权重将一小段边缘平移到远处，每次抓取还进行重采样、增加材料点，因而多次操作可累积细长突出。Catmull–Rom 仅平滑输出，还可能越过控制点，不能限制材质的真实伸长。

现在保持固定的材质网格，采用耳朵、主体、头部、手臂和脚部的连续分区形变场。所有分区具有平滑的权重过渡，五官使用单独的刚性平移，避免随皮肤缩放或剪切。

几何约束在形变过程中执行：耳朵长度为基础值的 0.67–1.36 倍，并与最低厚度耦合；主体宽度为 0.80–1.28 倍，高度为 0.82–1.20 倍。相邻材料边长比限制为 0.50–2.35，同时限制局部转角、主体面积、脸部安全区与轮廓自交。多个约束冲突时，从本次候选形态向上一个有效的用户形态回退，选取可行位置，不替换成初始模板。

轮廓采用位于控制点局部凸包内的三次 B 样条，避免插值过冲。阻尼弹簧作用于受限形变参数，显示过程也受几何验证保护。所有形变都修改真实轮廓坐标，不靠模糊滤镜遮盖问题。

原始概念图保留在物种档案中；当前交互形态遵循上述边界。

## Windows 用户：下载后双击运行

**[下载 Windows 10 / 11 运行包 ZIP](https://github.com/Anriri/biyesheji/raw/refs/heads/main/downloads/unnamed-creature-windows-v3.zip)**（约 15 MB）

1. 下载后右键 ZIP → **全部解压**，不要在压缩包内直接运行。
2. 打开解压后的文件夹，双击 **`start-windows.bat`**。
3. 浏览器自动打开后，点击 **开启摄像头 → 允许**。
4. 保持黑色启动窗口运行，关闭窗口会停止网页服务。

这个运行包已经包含构建后的网页、模型和 WASM，**无需安装 Node.js、Python 或 npm**。运行时在你自己的电脑上处理摄像头画面，不会上传。不要直接双击 `app/index.html`。如果直接下载链接不能打开，可进入仓库的 `downloads` 文件夹，打开 ZIP 文件并点击 GitHub 的下载按钮；私有仓库需先登录有访问权限的 GitHub 账号。

以下是开发者从源码运行和验证的方法。

**隔空手势使用真实 MediaPipe 识别。** 可主动切换到独立的鼠标模式直接拖动角色，摄像头失败时不会自动伪装为手势识别。没有后端、账号、数据库或视频上传。涂色和当前形状保存在本次会话中，刷新页面后恢复初始状态。

## 启动

推荐使用电脑上的最新版 Chrome 或 Edge，以及 Node.js **22.12+**（或 Node.js 24）。

在项目根目录运行：

```bash
npm ci
npm run dev
```

然后在运行项目的电脑上打开 `http://localhost:5173`（若端口被占用，以终端显示的端口为准）。点击 **开启摄像头**，在浏览器弹出的权限提示里选择 **允许**。模型首次初始化可能需要数秒，成功后右侧显示镜像画面、手部骨架及处理帧率。

安装会自动把 npm 包内的模型、WASM 和加载脚本复制到 `public/mediapipe/hands/`。**启动后的识别不需要访问 CDN 或外部模型地址**，也不需要 API Key。首次安装需要访问 npm registry；依赖版本由 `package-lock.json` 锁定。

> 摄像头只在 **localhost 或 HTTPS** 安全上下文中可用。用普通 HTTP 的局域网 IP 或远程 IP 打开页面，通常无法调用摄像头。远程部署应先构建并通过 HTTPS 提供 `dist`，不能直接双击 `index.html`。在 iframe 中嵌入时，宿主页还需允许摄像头权限。

## 鼠标与涂色

点击观察室下方的“鼠标塑形”，直接拖动耳朵、主体或四肢；拖动与手势使用同一个几何模型。点击“隔空手势”返回真实摄像头控制。涂色可选淡紫、薄荷、蜜桃，或通过“自选”颜色框调整。重置形态和撤销操作不会清除涂色。

## 手势测试

准备：光线均匀、手掌朝向摄像头、距离约 40–80 cm；只放入一只完整的手。镜像预览中向右移动，观察室的光标也向右移动。手指中点映射至整个观察室，不是直接在右侧视频上选中生物。优先看**观察室里的圆形光标**确定抓取位置。

| 测试 | 怎么操作 | 应看到的结果 |
| --- | --- | --- |
| 追踪与镜像 | 张开手掌，左右/上下移动 | 视频上出现 21 个关键点和连线；观察室光标同向移动；提示「等待手势」 |
| 隔空捏合 | 将拇指和食指靠拢，保持约 0.1 秒 | 距离条变黄，状态显示「已捏合」；在空白处捏合不会抓住生物 |
| 拉长左耳 | 张开两指，把光标移到左侧垂耳轮廓；提示「可以捏住」后捏合，缓慢向下拉长、向上缩短或横向调整宽度 | 状态显示「正在塑形」；左侧耳朵局部连续跟随，其他远处部位保留 |
| 拉长右耳 | 先张开手指，再抓住右耳并拉动 | 右耳独立伸长或改变方向 |
| 防尖刺 | 对同一部位多次向远处拉，或快速大幅移动 | 达到局部比例边界后不继续变尖变长，主体与四肢保持完整 |
| 五官协调 | 连续拉伸身体和耳朵 | 眼睛与嘴巴随头部轻微平移，大小与形状不被扯歪，始终位于脸内 |
| 撤销 | 点击“撤销一步”或按 Ctrl+Z | 恢复上一次塑形前的完整轮廓，最多保留 40 次操作历史 |
| 松手定型 | 拉伸过程中分开拇指和食指 | 结束抓取，轻微回弹后保留新形状，塑形次数增加；再次抓住可继续修改 |
| 身体变宽 | 把光标移到身体任意左/右侧，捏合后向外拉 | 被抓侧及邻近曲线平滑延伸，身体变宽 |
| 身体变高 | 抓住身体侧面下半部轮廓，向下拉 | 身体向下延伸、变高；向上拉可以缩短，下方有安全范围限制 |
| 弹性与表情 | 缓慢/快速拉动后松手，静置观察 | 曲线有柔软跟随和轻微回弹，塑形时嘴形变化，生物会呼吸和眨眼 |
| 丢失追踪 | 抓住并拉动后，将手移出镜头超过 350 ms | 自动结束抓取并保留形状，不会持续乱拉；重新入镜后可继续 |
| 主动结束 | 抓取时按 Esc | 立即定型；先张开手指，再进行下一次抓取 |
| 重置 | 点击「重置形态」 | 恢复初始耳朵和身体，次数归零；若正在捏合，需要先松开再抓取 |
| 关闭摄像头 | 点击「关闭摄像头」 | 停止所有视频轨道并清空预览，形态保留；可重新开启 |

如果总是捏不住，先看光标是否显示「可以捏住」，再稍微提高「捏合灵敏度」。手指距离按掌宽归一化，并有进入/退出双阈值及 65 ms 时间防抖。抓取使用从起点起的相对位移，避免第一次捏合时轮廓跳位。每次抓取需经历张开 → 捏合，不能捏着手在空白处滑入后自动抓取。

## 常见问题

- **拒绝摄像头权限**：在地址栏的摄像头/网站设置里改为允许，点击「重新开启摄像头」。页面会显示明确错误，不会退回到鼠标假手势。
- **没有设备 / 设备被占用**：连接摄像头，关闭会议等占用摄像头的应用，再重试。
- **模型或 WASM 加载失败**：重新运行 `npm ci`，确认 `public/mediapipe/hands` 中有本地资源，再刷新页面。部署时必须包含完整 `dist/mediapipe`，并允许本地 WASM 执行；严格 CSP 需允许 `'wasm-unsafe-eval'`。
- **初始化超时 / WebGL 出错**：使用支持 WebGL 的现代浏览器并启用硬件加速，关闭其他占用 GPU 的标签页。引擎初始化超过 45 秒会给出提示。
- **追踪抖动 / FPS 低**：保证整只手入镜和充足照明，避免遮挡或快速转动手掌。该原型追踪一只手，背景有另一只手时可能切换识别目标，操作时请只让一只手入镜。
- **HTTPS 证书 / 权限策略问题**：使用浏览器信任的 HTTPS；嵌入第三方页面时检查 `Permissions-Policy` 和 iframe 的 `allow="camera"`。

## 构建与检查

```bash
npm run build           # 输出可部署到 HTTPS 静态站点的 dist/
npm run preview         # 本机预览生产构建
npm test                # 连续形变、定型、边界和手势防抖的单元测试
```

可选的浏览器自动化检查：

```bash
npx playwright install chromium
npm run test:browser
```

Linux 环境已有系统 Chromium 时，可用 `CHROMIUM_PATH=/usr/bin/chromium npm run test:browser`。无系统浏览器且缺少系统库时，按 Playwright 官方说明安装浏览器系统依赖。

自动化检查覆盖页面、移动端、真实鼠标拖动、涂色、撤销、五官刚性保护、拒绝授权、依赖失败，以及本地 MediaPipe 引擎处理视频帧。几何测试额外覆盖 300 次极端混合操作、重复拉耳、比例上下限、局部材质伸长、自交、弹性显示与松手定型。引擎测试使用 Chromium 的测试视频源来验证管线，**不能替代真实摄像头下的手势验收**。单元测试中的人工关键点仅用于验证数学逻辑，不参与产品运行，也不是 UI 识别降级方案。

## 项目结构

```text
src/main.js                   页面、交互状态、SVG 动画与摄像头预览
src/sculpture.js              连续曲线、区域命中、软拉伸和阻尼回弹
src/gesture.js                掌宽归一化捏合、镜像坐标、平滑和防抖
src/tracking.js               真实摄像头、MediaPipe 推理、资源和权限处理
src/style.css                 响应式视觉样式
scripts/prepare-mediapipe.mjs  准备本地模型和运行文件
tests/                        单元与浏览器自动化测试
```

本原型验证 2D 隔空捏塑的可行性，不追踪手指对三维模型的压力或真实物理体积。形变限制在可视范围内，以保留完整轮廓。当前会话的形状不会自动保存到磁盘。
