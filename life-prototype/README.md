# 未名生物收容所 · 初生动画

在原有生命感动画和身体塑形上增加自由肢体，保留同一只纯白软团子和一双深色眼睛。初始形态仍没有嘴巴、耳朵、四肢、额头芽或花纹；肢体由用户自己拉出。

## 直接运行

把压缩包**全部解压**，双击 `index.html`，用 Chrome、Edge、Firefox 或 Safari 打开。

下载运行包时，双击根目录的 **`打开动画.html`** 即可；这是包含全部样式和脚本的单文件版。仓库中的同一文件叫 `standalone.html`。

无需安装工具、输入命令、启动服务器、授权摄像头或连接网络。不能在压缩包预览窗口里只打开一个文件，`index.html`、`style.css` 和 `creature.js` 需要在同一个文件夹里。

角色会自动开始活动。观察约 15 秒，可以看到轻柔浮动、摇晃、落下压扁、弹起拉长、轮廓延迟回弹、眨眼和缓慢改变视线。

## 塑形

### 自由生成肢体（鼠标版）

1. 点击“长出肢体”，按住身体边缘向外拖动，再松手。可在不同位置重复添加多个肢体；只点击或在身体中央拖动不会添加。
2. 点击已有肢体选中。拖动末端空心圆点，调整长度和方向；拖动中间实心圆点，调整弯曲。根部固定在对应的身体材料位置，沿身体外侧可以大范围改变方向。
3. 用“粗细”滑块从细触须调成粗手臂。选中的肢体可点击“删除肢体”或按 Delete / Backspace 删除。按 Esc 取消选中。
4. 点击“揉捏身体”继续原有塑形；肢体根部会跟随身体变形与待机动画。松手时肢体轻微弹性回摆，再停留于设定的形态。长肢体松手后，视图会缓动扩展以保持末端可见。
5. 创建、末端拖动、弯曲、粗细、删除、身体塑形和重置共用最近 40 步撤销。重置会同时清除肢体并恢复身体，重置也可以撤销。

### 节外生枝

保持“长出肢体”模式，按住已有肢体的侧边继续向外拖，就会在这个位置长出分支。新分支上也能重复操作，形成多级结构；末端和中间的圆点仍用于编辑当前段，不会误生成分支。单击肢体而不拖动只会选中它；“揉捏身体”模式下点击肢体也可选中编辑。

新分支默认比父段细，之后可以单独调粗细、弯曲和长度。分支记录父段 ID 与父轮廓的材料位置，用父段正在显示的曲线逐层求解根部和切线；父段拉长、变弯、变粗或弹性晃动时，子分支与更深层分支同时跟随，不使用固定的世界坐标贴线。父段和子段共用纯白填充、根部过渡和一次合成阴影。

删除选中的段时，它下面的子分支也一起删除，避免留下悬空肢体；其余兄弟分支和独立肢体不会删除。撤销会恢复整支结构及之前的参数。可以先拖动主干末端，观察子分支跟随，再删除某条子分支并撤销，验证连接和历史记录。

肢体是独立的三次贝塞尔中心曲线，沿法线生成渐变宽度的封闭轮廓，末端圆润封口。根部使用与身体切线相接的曲线过渡，并深入主体；填充相互覆盖后统一合成阴影，没有内部描边或每条肢体单独的阴影。连接不依靠模糊填缝，也不通过放大身体模拟新增肢体。根部的材料索引与局部坐标绑定保证身体变形后仍然连接。肢体控制参数采用独立的阻尼弹簧；保存的数据与显示回弹分离。

当前为纯前端会话内原型，刷新页面会回到初始形态；无需摄像头或联网。

### 身体揉捏

增强版保持同一角色和动画，单次拖动位移上限由 110 提高到 300 个 SVG 单位（2.73 倍），同时放宽宽高、面积和材质伸长约束。同样的测试路径下，向右拉伸的最大材料位移从约 96 提高到 256，向上拉伸从约 67 提高到 192，分别约为旧版的 2.66 与 2.86 倍。

1. 按住身体轮廓的任意位置，缓慢拖动。向外拉长，向内压扁，也可以侧向修改局部曲线。身体内部也可以抓取，会作用于最近的边缘。
2. 松手会轻微回弹，再保留你选择的轮廓。浮动、摇晃、波动和眨眼一直叠加在这个形状上，不会覆盖你的修改。
3. 点击“撤销”或按 Ctrl+Z / ⌘Z 撤回上一步。支持最近 40 步。
4. 点击“重置”恢复初始形状；如果后悔，重置操作也可以撤销。按 Esc 结束当前拖动。

长距离拖动会逐渐带动更宽的一片相邻材料，形成明显但平滑的局部突出。从顶部下压时，身体会向两侧摊开；横向往内挤压时，身体会沿纵向鼓起。每次操作都基于上一次保存的轮廓，支持连续叠加。仍保留曲率、自交与眼睛容纳约束，避免断裂或细长尖刺。

### 连续塑形修正

旧版将面积与周长始终限制为初始团子的固定倍数；向两边拉宽后，面积接近上限，再向上拖会被整体回退，表现为“拉不动”。现在保留宽高和坐标范围，移除共享面积上限，周长按当前轮廓宽高限制，防止横向塑形耗尽纵向空间。横纵位移还会分别投影到各自的安全边界，达到宽度上限时，鼠标稍微横向偏移也能继续向上拉。

测试方法：先把左右两边分别拉宽，松手；再按住当前顶部向上拉，应明显变高并保留宽度。点击撤销，只撤回向上拉这一步。也可以先从顶部压成薄饼，再横向拉宽，最后从顶部拉高。仍受画布范围、最小厚度、材料伸长、曲率、自交和眼睛安全区限制。

### 局部小角内收修正

旧版还会因为一个控制点到达曲率或材料边长限制，将整段拖动回退到几乎零位移。现在先让违反约束的材料边和相邻角局部放松：通过边长投影和局部曲率平滑，将小角圆润地收进主体，再检查完整几何；保持固定的 32 个材料点，不重建模板、不模糊渲染、不替换原形状。无法安全接受的移动仍回退到本次操作前的用户轮廓。

直接拖动与挤压引起的横向/纵向鼓胀分别求解，先满足抓取点移动，再在剩余空间内加入鼓胀。远处边界不会通过鼓胀量抵消向内揉捏。测试覆盖旧版卡住的左下凸角、受远处曲率影响的局部内推、连续拖动、重新外拉和逐步撤销。

## 实现

- 身体用纯白填充的 SVG 连续 B 样条绘制，不使用 3D 模型或图片贴图。
- 共相位的浮动与挤压控制落下压扁、弹起伸长；横纵缩放互为倒数，保持近似体积感。
- 低频叠加产生细微不对称，轮廓控制点通过有阻尼的弹簧跟随目标形态。
- 眼睛保持独立大小，使用不定间隔的眨眼和有缓动的视线变化。
- 鼠标坐标扣除实时浮动、旋转和呼吸缩放；通过宽范围局部权重修改持久化的基础轮廓。显示层的阻尼弹簧负责柔软跟随和松手后的轻微回弹。
- 拖动时提高跟随刚度；松手时按本次局部位移施加受限的回弹速度，即使拉住并停留后再松手，也会有 Q 弹晃动。回弹只改变显示层速度，不改变保存的形状。约 1.4 秒后回到原有待机弹性参数，背景动画幅度保持原样。
- 塑形数据与动画时钟独立，撤销或重置不会重置眨眼、视线或摇晃。
- 页面隐藏时暂停模拟时钟，恢复时不快速跳动；减少动态效果偏好会降低动作幅度。

三个文件即可运行，不引用外部字体、CDN、模型或框架。旧版塑形项目保留在仓库根目录，本原型不加载它。

开发者需要重新生成单文件和 ZIP 时，在仓库根目录运行 `python3 scripts/package-life.py`。普通使用者不需要 Python。
