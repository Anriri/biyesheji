# 未名生物收容所 · 初生动画

在原有生命感动画上增加鼠标塑形，保留同一只纯白软团子和一双深色眼睛。没有嘴巴、耳朵、四肢、额头芽或花纹；画面底部仅增加“撤销”和“重置”。

## 直接运行

把压缩包**全部解压**，双击 `index.html`，用 Chrome、Edge、Firefox 或 Safari 打开。

下载运行包时，双击根目录的 **`打开动画.html`** 即可；这是包含全部样式和脚本的单文件版。仓库中的同一文件叫 `standalone.html`。

无需安装工具、输入命令、启动服务器、授权摄像头或连接网络。不能在压缩包预览窗口里只打开一个文件，`index.html`、`style.css` 和 `creature.js` 需要在同一个文件夹里。

角色会自动开始活动。观察约 15 秒，可以看到轻柔浮动、摇晃、落下压扁、弹起拉长、轮廓延迟回弹、眨眼和缓慢改变视线。

## 塑形

1. 按住身体轮廓的任意位置，缓慢拖动。向外拉长，向内压扁，也可以侧向修改局部曲线。身体内部也可以抓取，会作用于最近的边缘。
2. 松手会轻微回弹，再保留你选择的轮廓。浮动、摇晃、波动和眨眼一直叠加在这个形状上，不会覆盖你的修改。
3. 点击“撤销”或按 Ctrl+Z / ⌘Z 撤回上一步。支持最近 40 步。
4. 点击“重置”恢复初始形状；如果后悔，重置操作也可以撤销。按 Esc 结束当前拖动。

轮廓设有适度的长度、面积、曲率和自交约束，保留柔软团子的完整度，避免出现细长尖刺或压到无法容纳眼睛。眼睛随实际形变移动，保持自身尺寸，并对可见 SVG 轮廓进行安全检查。

## 实现

- 身体用纯白填充的 SVG 连续 B 样条绘制，不使用 3D 模型或图片贴图。
- 共相位的浮动与挤压控制落下压扁、弹起伸长；横纵缩放互为倒数，保持近似体积感。
- 低频叠加产生细微不对称，轮廓控制点通过有阻尼的弹簧跟随目标形态。
- 眼睛保持独立大小，使用不定间隔的眨眼和有缓动的视线变化。
- 鼠标坐标扣除实时浮动、旋转和呼吸缩放；通过宽范围局部权重修改持久化的基础轮廓。显示层的阻尼弹簧负责柔软跟随和松手后的轻微回弹。
- 塑形数据与动画时钟独立，撤销或重置不会重置眨眼、视线或摇晃。
- 页面隐藏时暂停模拟时钟，恢复时不快速跳动；减少动态效果偏好会降低动作幅度。

三个文件即可运行，不引用外部字体、CDN、模型或框架。旧版塑形项目保留在仓库根目录，本原型不加载它。

开发者需要重新生成单文件和 ZIP 时，在仓库根目录运行 `python3 scripts/package-life.py`。普通使用者不需要 Python。
